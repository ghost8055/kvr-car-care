# KVR Car Care

Installable web app for the KVR Car Care workshop and customer portal.

## GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Open the published HTTPS address on your phone.

## Install on a phone

- **Android:** Open the published address in Chrome and select **Install app** or **Add to Home screen**.
- **iPhone:** Open the published address in Safari, tap **Share**, then **Add to Home Screen**.

The app shell is cached for offline use after its first successful load.

## Demo limitations

This is a static front-end demo. Customer, vehicle, and service data is saved in browser local storage and does not sync between devices. It does not provide authentication, a shared database, or server-delivered notifications. Do not enter real customer information until a secured backend and access controls are added.
